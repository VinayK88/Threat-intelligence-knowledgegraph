# Contributing

Contributions are welcome.

Before opening a pull request:

```bash
python -m unittest discover -s tests -v
```

Good contribution areas:

- STIX 2.1 adapters
- TAXII adapters
- ATT&CK data adapters
- entity resolution
- temporal graph support
- provenance
- graph visualization
- embeddings
- graph ranking
- additional defensive correlation examples

Please keep included data synthetic or openly redistributable.
